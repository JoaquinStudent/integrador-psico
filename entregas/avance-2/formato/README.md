# Formato

Plantillas y formatos que entrega el docente. Son **insumo**, no entregable: lo que
se produce a partir de ellos vive en `01-alternativas/` … `07-informe/`.

Convencion de nombres (ver `sdd/domain.md`): kebab-case, minusculas, sin acentos
ni espacios. Por ejemplo:

- `formato-srs.md`
- `formato-informe.md`
- `formato-project-charter.md`

Este README existe para que git versione el directorio aunque este vacio.
